# Smart Blood Donor Finder System (BloodBridge)

## Project Overview

This project is a web-based Smart Blood Donor Finder System developed to connect blood donors with patients during emergencies. The platform provides an efficient and user-friendly solution for donor registration, emergency blood requests, donor profile management, and blood donation awareness.

The website is designed with a modern and responsive user interface, featuring interactive dashboards, animated sections, chatbot assistance, and mobile-friendly layouts. The main purpose of this project is to simplify the process of finding blood donors quickly while demonstrating front-end web development skills.

## Setup Instructions

1.  Download or clone the repository:
   ```
  git clone https://github.com/amrithapn/BloodBridge.git
   ```
2. Open the project folder.
3. Ensure all files (images and video) are in the correct directory as shown above.

## How to Run the Project
1. Open the project folder in Visual Studio Code.
2. Locate the index.html file.
3. Right-click on index.html.
4. Select Open with Live Server.
5. The website will open automatically in your browser.

## Deployment
This project can be hosted using GitHub Pages:
1. Go to repository settings
2. Navigate to Pages
3. Select branch: main
4. Save and access the generated live link
